Название игры: Алтарь Жадности

Жанр: RPG, пошаговая, в консоли

Краткое описание:
Игра представляет собой текстовое RPG, в которой игрок опускайсь всё глубже в загадачную пещеру, находит разный противников и сокровища. Чем глубже лезишь, тем сложнее вылести целым. После похода приносишь дань Алторю, что даст тебе сил на новый свершения. 

Основные особенности:
Разные начальные персонажи
Система прокачики лагеря и персонажа
Интерактивные NPC
Лаберинты с наградами, монстрами и боссами
